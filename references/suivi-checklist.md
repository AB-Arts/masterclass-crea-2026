# La check-list de suivi

Sert à dire au participant **où il en est** et **quelle est sa prochaine étape**. Pose les
questions une à une. Pour chaque étape non faite, explique-la avec le fichier indiqué.

## Après la séance 1 · à faire avant le mardi 17 novembre 2026

| # | Étape | Comment vérifier | Aide |
|---|---|---|---|
| 1 | Avoir un abonnement Claude qui permet de construire | Le participant sait quelle formule il a | `03-modeles-tokens-abonnements.md` |
| 2 | Installer l'application Claude Desktop | Il voit les onglets Chat et Code | `04-claude-chat-code-skills.md` |
| 3 | Créer son compte GitHub | Il peut se connecter sur github.com | `05-github.md` |
| 4 | Créer un premier dépôt **privé** | Le dépôt apparaît dans sa liste, avec la mention Private | `05-github.md` |
| 5 | Connecter GitHub à Claude | Claude confirme la connexion, ou GitHub apparaît dans les connecteurs | `05-github.md` |
| 6 | Créer un dossier de travail et l'ouvrir en mode Code | Le nom du dossier s'affiche sous la zone de saisie | `06-demo-reporting-pas-a-pas.md` |
| 7 | Refaire la démo, ou construire un petit outil à soi, avec des données fictives | Un aperçu s'affiche à droite | `06-demo-reporting-pas-a-pas.md` |
| 8 | Faire un premier commit | Le dépôt GitHub affiche 1 commit | `06-demo-reporting-pas-a-pas.md` |
| 9 | Demander une modification et faire un deuxième commit | Le dépôt affiche 2 commits | `06-demo-reporting-pas-a-pas.md` |
| 10 | Réfléchir à **son** idée de prototype | Une phrase : « un outil qui m'aide à… » | `01-prototype-et-etat-desprit.md` |

Les étapes 1 à 5 sont l'essentiel. Le formateur l'a dit : « si vous arrivez à travailler dans
un dossier et à versionner sur un dépôt, on a tout gagné ».

Rappels à glisser : dépôt privé, aucune clé d'API dans un chat, données fictives.

## Le fichier de suivi

Si tu peux écrire dans le dossier du participant, propose de créer ou de mettre à jour
`suivi-crea.md` avec ce modèle :

```markdown
# Mon suivi · Module 5 CREA · Prototypage avec l'IA

Dernière mise à jour : [date]

## Mon idée de prototype
[une ou deux phrases]

## Séance 1 · avant le 17 novembre
- [x] 1. Abonnement Claude
- [ ] 2. Claude Desktop installé
- [ ] ...

## Où je bloque
- [blocage, avec le message d'erreur exact si possible]

## Questions pour Anthony
- [question à poser à la prochaine séance]
```

Ne jamais y écrire de clé d'API, de mot de passe ni de donnée confidentielle.
